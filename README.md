# Casino Roulette Web App

Una aplicación web interactiva de ruleta de casino desarrollada con HTML5, CSS3 y JavaScript (Vanilla). Permite gestionar una lista dinámica de ítems (con un mínimo de 26 elementos), cuenta con efectos de sonido realistas, animaciones de giro fluidas con físicas de desaceleración y un sistema de celebración con confeti para el ganador.

---

## Características Principales

* **Gestión Dinámica de Ítems:** Añade, elimina o limpia elementos únicos (mínimo de 26 elementos requeridos para habilitar el botón de giro).
* **Bloqueo de Duplicados:** Evita que se ingresen elementos repetidos para mantener la equidad de la ruleta.
* **Físicas de Giro Realistas:** Animación de la rueda y de la bola con una trayectoria en espiral suave que se ancla perfectamente en el casillero ganador sin saltos extraños.
* **Efectos de Sonido:** Audio integrado para clics, el giro de la ruleta y la celebración de victoria (con control de volumen y políticas de reproducción).
* **Modal de Ganador y Confeti:** Pantalla emergente interactiva que anuncia al ganador acompañada de una lluvia de confeti animada en HTML5 Canvas.
* **Carga Rápida de Demostración:** Botón de llenado rápido (Quick Fill - 26 Demo Items) para probar la ruleta inmediatamente.

---

## Tecnologías Utilizadas

* **HTML5 Canvas:** Renderizado gráfico en tiempo real de la rueda, los separadores, el cubo central, la bola y el confeti.
* **CSS3:** Estilos modernos, diseño responsivo oscuro estilo casino, efectos visuales con gradientes y transiciones fluidas.
* **JavaScript (ES6+):** Lógica completa del estado, manejo de eventos de DOM, animaciones basadas en requestAnimationFrame y gestión de elementos multimedia de audio.
